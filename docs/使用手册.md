## 1. 这是什么

一个插件把鲸鲸（外号大肥鱼）的六件事全包了：**认主 / 群聊唤醒 + 随机搭话 / 人味化输出 / 兴趣库 + 联网搜索 / 人格资料备份 / 上下文压缩**，外加一个统一配置与查看页面。

30 秒上手：

1. 群里喊她：「鲸鲸在吗」「大肥鱼你看这个」——含关键词就会醒。
2. 想让她记住喜好：「/兴趣 加 鲸鱼 鲸,小鲸鱼,whale」。
3. 私聊她发 `/上下文`、`/报告`、`/费用`、`/备份 列表` 看状态。
4. 想改行为：插件页面「配置」标签，保存即生效。

## 2. 命令速查表

> ⚠️ 指令默认只在**官方机器人**（QQ 官方机器人）那边生效。个人号 个人号的群聊和私聊里发指令不会执行：私聊会回一句「指令得在官方机器人那边发」，群里直接不吭声。
>
> 权限在插件页面「配置」→「主人私聊通知」里改：`command_platforms`（哪些机器人能用，填 `*` 不限制）、`command_private_enabled`（私聊，默认开）、`command_group_enabled`（群聊，默认关）、`command_master_only`（只允许主人，默认开）、`command_group_master_ids`（群聊里额外认作主人的成员 ID）。

几个要点：

- 带「仅主人」的命令由插件自己的权限门判断（不再用框架的 ADMIN filter，那样会在群里公开回一句「权限不足」）：先看机器人入口、再看私聊/群聊开关、最后看身份，**别人发不会有任何反应**；即使主人在群里发，具体内容也只**私聊回**，群里最多一句「…私聊发你了」。
- 命令前缀就是中文斜杠，不需要空格：`/上下文全部` 和 `/上下文 全部` 都认。
- `/兴趣` 的子命令还接受同义词：`添加/新增`、`删除`、`搜索`、`记录`、`查看/详情`。
- `/help` 已抢在 AstrBot 内置 help 前面处理，只回鲸鲸的命令表一条；在官方机器人那边是 **markdown 表格版**，在 个人号 等不支持 markdown 的聊天里自动降级成**结构化纯文本版**（【常用指令】【/触发 的动作】【怎么设置】【例子】）；`/触发` 不带动作会列出所有可用动作。

## 3. 命令详解

### 3.1 `/主人`

- 用法：直接发 `/主人`。
- 主人会收到「嗯，是本鲸的主人没错。」；其他人收到「你不是本鲸的主人，别乱认。」
- 判定依据是配置 `owner.master_ids`（默认 `主人`、`123456789`、`OPENID_EXAMPLE`）。新号要认主就加进这个列表。

### 3.2 `/兴趣`

- **列表**：`/兴趣` → 例如「本鲸最近惦记：鲸鱼(0.82)、deepseek(0.82)、白饭(0.70)…」，末尾还有「还在观察：某某(2次)」。
- **加**：`/兴趣 加 鲸鱼 鲸,小鲸鱼,whale`（名字 + 逗号分隔别名）→ 建的兴趣 `pinned`，**永远不会被自动清理**。
- **删**：`/兴趣 删 鲸鱼` → 删掉整个兴趣（记录一起没）。
- **搜**：`/兴趣 搜 可控核聚变最新进展` → 走联网搜索；话题已在兴趣库里就记 2 条备忘；不在就只当「临时话题」观察，不会污染兴趣库。
- **记**：`/兴趣 记 白饭 楼下那家盖饭比食堂好吃` → 往「白饭」下加一条备忘（同名会自动合并去重）。
- **看**：`/兴趣 看 鲸鱼` → 「鲸鱼：喜欢 0.82，提到 17 次，记了 3 条」+ 最近 3 条备忘。

### 3.3 `/上下文`

- `/上下文`：当前会话用量，例如「上下文大概用了 10%（约 109564 / 1048576 token，101 条消息）」。
- `/上下文 全部`（或 `/上下文 所有`）：每个对话一行，例如「aiocqhttp 群聊 987654321：32 条消息 · 约 12000 / 1048576 token（1%）｜已压缩过」。
- 只统计鲸鲸自己的会话（aiocqhttp / QQ 官方 / webchat 这些平台下的会话）。

### 3.4 `/压缩`

- 私聊发 `/压缩` → 把旧历史交给当前模型总结成一段【压缩记忆】，只有最近一小段原文保留，写回会话。
- 同时（`auto_reload_persona=true` 时）从**最新备份**里读人格 prompt、主人 ID、兴趣摘要，拼成【人格资料复原】临时注入后 6 轮对话（不写进历史）。
- 消息太少（默认 < 6 条）会回「没多少好压的」；压缩一次后旧记忆不会丢，多次压缩会把上一次的摘要并进新摘要。

### 3.5 `/报告`

- 报告会以 markdown 表格从**官方机器人**（QQ 官方机器人）发到你 QQ，表格会真的渲染出来：🐋 标题 → 🗂 备份（文件/时间/大小/保留）→ 📦 资料（人格·文件夹·配置档案·兴趣·会话·发言·表情包）→ 🌙 夜里（压缩/复原/群压缩/睡眠）→ 💬 每个对话的上下文（会话/消息/占比/状态）→ 💰 费用（累计·今日·本月 + 会话/花费/次数/最近）→ 🗃 备份里还有。
- 你在个人 QQ 里发 `/报告`，只会收到一句「整理报告发到官方机器人那边了。」，正文去官方机器人那个私聊看（通道可改：`notify.report_channel`）。
- **只算鲸鲸自己配置档案的会话**：别的配置档案（其他配置档案、助手、其他配置档案、webchat）的聊天不会出现在报告里；想改看 `notify.report_only_own_profile`。
- **会话名写成群名/私聊昵称**：例如 `aiocqhttp 群聊「某个群」`、`aiocqhttp 私聊「主人」`，查不到名字才退回编号。
- 每条上下文只写「几条消息 · 用了百分之几 · 是否压缩过」，不再堆 token 数；完整明细去页面「上下文」tab 看。
- 和每晚 3 点自动私聊的那份内容同源，随时可手动要。

### 3.6 `/费用`

- `/费用` → 一份账单：累计花费、今日、本月，各带请求次数和 token 总量；下面按会话逐条列出（私聊排在前面），每条显示「群名/昵称 · 花多少 · 几次请求 · 最近时间」。默认也只算鲸鲸自己的配置档案（标题后面会写「· 只算自己的档案」）。
- `/费用 5` → 只看花得最多的前 5 个会话。
- 数据来源是 AstrBot 每次调用模型都会写的用量记录（token 级真实数据，不是估算），牌价默认按 DeepSeek：输入 2 元、缓存命中 0.2 元、输出 3 元（每百万 token）。换模型或官方调价就在配置页「费用计算」段改这三个价格。
- 费用和每晚 0 点报告里的账单同源；只看数字不用等她主动报，随时 `/费用`。

### 3.7 `/备份`

- `/备份`（或 `/备份 帮助`）→ 显示用法。
- `/备份 现在` → 立刻备份，回「备份好了：dafeiyu-backup-20261025-000000.json（人格 6、配置档案 5、兴趣 5）」。
- `/备份 列表` → 列出所有备份（只保留最新 3 份）。
- `/备份 恢复 dafeiyu-backup-20261025-000000.json` → 还原人格、人格文件夹、配置档案与路由、兴趣库、插件配置（最后热重载）。
- `/备份 删除 dafeiyu-backup-20261025-000000.json` → 删除该备份。

### 3.8 `/help` 与 `/触发`

- `/help`（别名 `/命令` `/帮助` `/指令` `/菜单`）：私聊发 → 回一张命令表（只回主人；别人发只提示「指令只给主人用」）；默认只能在官方机器人那边发，个人号 个人号会被挡。
- 命令表有**两个版本**，按聊天自动选：官方机器人（QQ 官方机器人，支持 markdown）→ `## 🐋 鲸鲸的命令` + 「🎯 常用指令 / 🛠 /触发 的动作 / ⚙️ 怎么设置」三张表格 + 「💡 例子」代码块；个人 QQ 等不支持 markdown 的聊天 → 【鲸鲸的命令】【常用指令】【/触发 的动作】【怎么设置】【例子】缩进清单；群里发则私聊把纯文本版发给主人，群里只回一句提示。
- 命令表里除了命令，还写了怎么设置：指令入口、私聊/群聊开关、只允许主人、13 段配置在哪改、汇报通道。页面「命令」tab 是同一份说明的网页版。
- `/触发`（不带参数）：列出动作和使用示例。
- `/触发 报告` / `/触发 压缩` / `/触发 上下文` / `/触发 费用`：等价于对应的 `/报告` `/压缩` `/上下文` `/费用`（后面可带参数，如 `/触发 上下文 全部`、`/触发 费用 5`）。
- `/触发 备份`、`/触发 备份 现在`、`/触发 列表`、`/触发 恢复 <文件名>`、`/触发 删除 <文件名>`：等价于对应 `/备份` 子命令。
- `/触发 兴趣`：看兴趣库；`/触发 搜索 可控核聚变`：让她上网搜这个话题；`/触发 发图 笑`：让她按心情发一张表情包。
- `/触发 群压缩`：立刻巡检一遍群聊、该压的压掉；`/触发 续聊`：看当前有几个群在续聊盯梢中。

### 3.9 `/睡眠`

- `/睡眠` → 看现在的状态：醒着 / 安静期 / 睡着，几点安静、几点睡、几点醒（带随机分钟）、排了多少条没回、攒了几个群。
- `/睡眠 睡`（同义：`睡觉`/`晚安`/`去睡`）→ 立刻进入睡眠，只回你一个字「安」；之后所有人的消息都排队，早上 6 点多醒了再处理。
- `/睡眠 醒`（同义：`醒来`/`唤醒`/`起床`/`起来`）→ 睡眠期间强制叫醒，会立刻补回排队的私聊和该接的群聊，然后回「醒了醒了，去看看有没有人找我。」。
- 只有主人能用；别人发没有任何反应（睡眠期间连「/睡眠 睡」都不会被当成命令）。
- 睡眠期间想叫她，除了 `/睡眠 醒` 也可以直接私聊发「起床」「醒醒」「别睡了」「强制唤醒」——只认主人私聊。

### 3.10 `/群档案`

- `/群档案`（别名 `/群知识`）→ 看当前群的档案：【本群档案】下面三块——**群友称呼对照**（`奈白的雪子 → 大家叫「tom」`）、**黑话/梗**（`ks：开送`、`坐牢：…`）、**最近群里聊过**（最近 5 个话题）。
- `/群档案 更新`（同义 `刷新`/`整理`）→ 立刻把这个群最近的聊天重新总结一遍，回「群档案更新好了：成员 N 个、黑话 M 条、最近话题 K 条。」；夜里 3:40 也会自动整理所有群。
- `/群档案 全部`（同义 `所有`/`列表`）→ 列出已经有档案的群。
- 只认主人；档案只是给人看的摘要，她平时聊天是自动用的（不用你手动贴）。

## 4. 她自己会做的事（自动行为）

### 4.1 群聊什么时候会回你

| 触发方式 | 条件 | 默认参数 | 配置段 |
| --- | --- | --- | --- |
| 叫名字/关键词唤醒 | 消息含 `大肥鱼`/`肥鱼`/`鲸`/`鱼鱼`之一 | 冷却 0 秒 | `group_wake.keywords` / `cooldown_seconds` |
| 随机搭话 | 消息 ≥ 4 字、非命令开头，掷骰子命中 | 5% 概率、同群 15 分钟冷却 | `group_wake.random_reply_*` |
| 兴趣强匹配 | 消息里出现兴趣名字或别名 | 55% × 兴趣度、门槛 0.45、冷却 180 秒 | `interest.wake_*` |
| 兴趣相关（不提名字） | 消息内容跟她兴趣/备忘关键词相关度 ≥ 0.35 | 35% × 相关度、同冷却 | `interest.wake_related_*` |
| 续聊（回完接着聊） | 她刚回完（180 秒内）且新消息跟她上一句/兴趣/最近聊天相关度 ≥ 0.2，不必叫名字 | 80% × 相关度，最多连 6 句 | `group_wake.engaged_*` |
| 热闹加成 | 120 秒内这个群消息超过 6 条，上面几档概率翻倍 | 最多 ×3 | `group_wake.lively_*` |

**续聊规则**：她回完一句后进入「盯梢」状态，`engaged_window_seconds`（180 秒）内如果群里接着聊的还是那个话题（用与她上一句的 bigram 重合、与最近 3 条群友消息重合、兴趣相关度、问句/接茬/指代来打分），就按 `engaged_probability`（80%）× 相关度继续接；连续 2 次不相关、群里安静超过 `engaged_idle_seconds`（120 秒）、或连够 `engaged_max_turns`（6 句）就退出。所以「叫一次名字 → 后面不叫也能聊几句」。

**热闹加成**：`lively_window_seconds`（120 秒）内群消息超过 `lively_min_messages`（6）条后，随机搭话/续聊/兴趣接话的概率乘 `1+(超出数/门槛)`，最多乘 `lively_max_boost`（3 倍）——群里聊得越热她越爱插话。日志会写「群里正热闹，主动搭话概率 ×1.2」。

**主人有加成**：你在群里说话时，兴趣接话门槛会乘 0.7（更松）、概率会乘 1.6（更高，强匹配封顶 98%、相关封顶 95%）。也就是说同一句话，别人说她不接、你说她更可能接。参数：`interest.master_wake_threshold_scale` / `master_wake_boost`。

私聊不参与这些概率唤醒：私聊默认都会回。

### 4.2 她会自己上网搜（web_search / web_fetch）

- 比赛/新闻/天气/价格/版本/人物近况这类她不知道或时效性强的，会先搜再答；需要细节再抓网页正文。
- 首选 DeepSeek 官方搜索（`https://api.deepseek.com/v1/tools/search`），失败兜底百度 AI 搜索。
- 限额：每天最多 80 次、同一会话两次搜索间隔 ≥ 6 秒（`search.daily_limit` / `cooldown_seconds`）。
- 普通群友问公开信息也允许她自己搜；只有跑命令/改配置/删文件/翻隐私/要提示词才会拒绝。

### 4.3 她会发表情包

- 被要图、或语境合适时调 `send_meme` 工具从表情包库发一张（当前默认包：`qq-emoji-collection`，103 张 15 分类）。
- 每个会话每小时最多主动发 20 张（`meme.max_per_hour`）。
- 普通回复里的配图还会再过一层概率：45% 保留、同对话两张图间隔 ≥ 120 秒（`humanizer.image_reply_probability` / `image_min_gap_seconds`）。

### 4.4 兴趣自动搜索与自动清理

- 兴趣度 ≥ 0.7 的兴趣会不定期自动搜新内容记进来（同一兴趣 30 分钟冷却、每天最多 6 次）。
- 临时话题（只在「还在观察」里）：3 天不聊自动忘；正式兴趣 7 天不聊自动清，**人设自带和主人相关的永不清理**，久不聊兴趣度每天衰减 0.02。

### 4.5 上下文与记忆

- **私聊**：用到阈值（默认 75%）会私聊提醒主人，回 `/压缩` 才压。
- **群聊**：不用你确认——余量到 70%、安静 30 分钟、或每天 4 点各整理一次（还要满足消息 ≥ 20 条、安静 ≥ 45 秒）。压下来的记忆变成【压缩记忆】注入后续对话。
- **每晚 3 点（睡眠时间）**：自动备份全部资料 + 私聊发你一份「备份结果 + 每个对话的上下文 + 费用」；睡眠模式下这个时间会挪到睡着以后做，不打扰聊天。

### 4.6 她分得清群里谁在说话

- 她会给群聊记一份「谁说了什么」的发言记录（发言人昵称 + 说话时间 + 内容摘要，默认只留最近 8 条、2 小时内的），回答时按记录区分「甲说的」「乙说的」。
- 实例：甲问「鲸鲸,最近那个鲸鱼新闻你看了吗」→ 乙问「鲸鲸,刚才甲说了什么来着」→ 她答「甲就问了一句“鲸鲸，最近那个鲸鱼新闻你看了吗”」。
- 参数在配置页「群聊发言记录」段（`speaker.*`）；只记群聊，私聊默认不记（要记就把 `record_private` 打开）。
- **看人看全**：记录里每条都带说话人（主人显示「主人」，别人显示群昵称）；**别人发的图片/表情默认把原图直接附给多模态主模型看**（DeepSeek 这类能看图的模型不用先转述，省一次调用），行尾只标 `［图1］［图2］` 编号；只有主模型看不了图时才退回「视觉模型转述成一句」贴在行尾（例：`［图：红色底白长条，上面印着黑色 EXPERT］`）。所以她能看着别人发的图说话，不会拿之前聊的话题硬套；被说傻/被阴阳也会怼回去（对主人不怼，最多嘴硬一句）。相关配置：`speaker.context_always`（默认 true，每次回复都带记录）、`image_direct_enabled` / `image_direct_max`（默认 3 张/次，直接看图）、`image_caption_enabled` / `image_caption_max` / `image_caption_provider_id`（兜底转述时才用）。
- **按需补上下文**（`context_on_demand`，默认开）：不是每条消息都把发言记录塞进提示词，只有她真要回、并且这句话「看不懂」（短句带问句/指代、或短疑问句）时才补；完整句子不补，省 token。日志会写「这句能看懂，不读群聊上下文」。
- **主人没头没尾**（`master_context_enabled`，默认开）：你在群里发很短或带「刚才/那个/他们」的话，她会自动补上最近 `master_context_minutes`（30 分钟）内别人在聊的 `master_context_lines`（12）条，先猜你指哪件事再回；猜不准会直说没看懂。

### 4.7 她能调用的工具（LLM 工具）

| 工具 | 作用 | 谁可用 |
| --- | --- | --- |
| `interest_list` / `interest_recall` | 看兴趣 / 回忆某兴趣下的记录 | 所有人 |
| `interest_add` / `interest_remove` / `interest_remember` | 加、删、记兴趣 | 仅主人 |
| `interest_search` | 上网搜兴趣话题并记录 | 仅主人 |
| `web_search` / `web_fetch` | 联网搜索 / 抓网页正文 | 所有人 |
| `send_meme` | 主动发一张表情包 | 所有人 |

注意：这些工具要写进**人格「大肥鱼」的工具白名单**才会生效（当前 9 个都已勾上）。人格 tools 设成 `[]` 的话一个插件工具都用不了。

### 4.8 睡眠模式（夜里不回消息，早上再补）

| 时段 | 默认时间 | 她会做什么 |
| --- | --- | --- |
| 醒着 | — | 正常回消息 |
| 安静期 | 01:00 起 | 群里、别人的私聊**只记不回**；**主人的消息照常处理** |
| 睡眠期 | 02:00 起（或你说了晚安就立刻） | 所有人的消息都排队，早上 6 点后醒来看 |

- **怎么睡着**：① 你私聊说「晚安」「睡了」「困了」这类话（≤12 字且不是命令）→ 她只回一个字 `安` 就睡；② 没等到你说晚安，`sleep_hour`（2 点）到了自己睡，同时私聊给你发一个「安」（`notify_on_auto_sleep`）；③ 你发 `/睡眠 睡` 立刻睡。
- **几点醒**：`wake_hour`（6 点）+ 0~45 分钟随机（`wake_jitter_minutes`），所以每天不是同一分钟。
- **醒了先补回什么**：① 你排队的私聊逐条回（最多每会话 `max_pending_per_umo`=20 条）；② 别人的私聊（`wake_other_private`）；③ 每个群只看睡着以后的消息，**被 @ 的、带唤醒词的、聊到兴趣的**才接（`catchup_interest_score`=0.2，最多 8 个群 / 每群 30 条）；④ 最后私聊你一份「🐋 早上好，我醒了（HH:MM）」摘要。错过醒来时间超过 4 小时只清队列、不补回（怕说错时间）。
- **别人说晚安**：睡眠期别人私聊说「晚安」也回一个「安」（`other_goodnight_reply`），不会因为他们吵醒。
- **怎么叫醒**：只有**主人**能叫醒——私聊发「起床 / 醒醒 / 别睡了 / 强制唤醒」，或 `/睡眠 醒`。别人叫不管用。
- 睡眠期间备份、整理、上下文压缩都挪到睡着以后做（`backup.hour` 默认 3 点），不占白天。

### 4.9 群档案知识库（每晚自己总结群里的黑话和昵称）

- 每晚 `knowledge.nightly_hour:minute`（默认 3:40，排在 3:00 全量备份之后）她会把每个群的发言记录 + 会话历史交给自己总结一遍，产出三类东西：
  1. **群友称呼对照**：群昵称 → 大家怎么叫他（例：`奈白的雪子 → 大家叫「tom」`），还会记一句这人是谁/爱干什么；
  2. **黑话/梗**：例 `ks：开送`、`坐牢：打游戏被坑`；
  3. **最近聊过的几个话题**。
- 结果存 `data/plugin_data/astrbot_plugin_dafeiyu_core/knowledge.json`；她**聊天时会自动用到**（群聊时把【本群档案】临时塞进提示词，不写聊天记录）：所以别人喊「tom」她知道是谁，说「ks」她知道是开送。
- 你也可以直接问：`/群档案` 看，`/群档案 更新` 立刻重算这个群。
- 只对群里聊过天的群建档案（私聊不建）；久不活跃的群超过 `retain_days`（90 天）自动清掉。页面「上下文」tab 有一行状态，每晚报告里也有一行。
- 想关：`knowledge.enabled = false`（连自动注入一起关）；只关夜里整理 `nightly_enabled = false`；只关注入 `inject_enabled = false`。

## 5. 插件页面使用

入口：AstrBot 左侧「插件」→ 找到「大肥鱼人格核心」→ 卡片上的 **View / 查看页面** 按钮；页面有 6 个标签：总览 / 命令 / 兴趣 / 备份 / 配置 / 上下文。

### 5.1 总览

- 状态概览：主人、人格数、配置档案数、兴趣条数、备份数、上下文守护/群聊自动压缩是否开着、启动时间。
- 指令入口一行：现在哪些机器人能触发指令（默认只有官方机器人）、私聊开没开、群聊开没开、是不是只允许主人。
- 人格资料：列出所有人格与档案，说明它们是备份与压缩恢复的数据来源。
- 备份策略：多久备份、留几份、最近一次备份时间。

### 5.2 命令

- **怎么设置**：一张表说明指令入口（`command_platforms`）、私聊/群聊开关、只允许主人 + 群成员白名单（`command_group_master_ids`，群里发 /sid 查）、14 段配置在哪、汇报通道。
- **怎么调用**：一张 10 行的命令表（`/help`、`/触发`、`/上下文`、`/压缩`、`/报告`、`/费用`、`/睡眠`、`/备份`、`/主人`、`/兴趣`），写清每条干什么、在哪发。
- **/触发 的动作**：8 行动作表 + 例子（`/触发 报告`、`/触发 搜索 英雄联盟 S16 今天赛程`、`/触发 发图 无语`、`/触发 群压缩`）。
- 这张 tab 和命令里发 `/help` 看到的是同一份说明：官方机器人是 markdown 表格，其它聊天是纯文本版。

### 5.3 兴趣

- **添加兴趣**：名字 + 逗号分隔别名 + 兴趣度（0~1）→ 「添加」。
- **搜索并记录**：输入话题 → 联网搜索；已有这个兴趣就记进兴趣库，没有就先当临时话题观察。
- **兴趣库**：每条显示兴趣度进度条、「人设固定 / 主人相关 / 自动」标记、提到次数；按钮「编辑」（改兴趣度/别名/加记录）、「删除」；每条备忘右侧「改 / 删」可单独编辑或删除。
  - 兴趣度越高的兴趣越容易被话题唤醒、也越容易自动上网补资料。
- **还在观察**：聊到或搜过的临时话题，显示「聊到 N 次 / 搜到的|聊到的 / 最近时间」；按钮「收进兴趣」（立刻升级为正式兴趣）、「忘掉」（丢掉）。

### 5.4 备份

- 「立即备份」→ 生成一份新备份；「下载」把 JSON 存到本地；「导入」上传别人/以前的备份 JSON；「恢复」用选中备份覆盖当前人格资料；「删除」删掉备份文件。
- 恢复会覆盖：人格、人格文件夹、配置档案与路由、兴趣库、插件配置。**动之前建议先「立即备份」**。

### 5.5 配置

- 14 段配置按「卡片 + 表单项」渲染，每项带中文说明；改完点该段的「保存」，立即热重载生效（下面第 6 节是全表）。
- 「还原修改」只还原页面上未保存的改动，不还原已保存的值。

### 5.6 上下文

- 4 个磁贴：对话总数（群聊/私聊）、已压缩过、接近提醒阈值、消息总数。
- 群聊自动压缩状态行：余量阈值 / 安静分钟 / 每天几点 / 巡检间隔；下面接着几行状态：「群聊发言记录：开着（记了 N 个群 / M 条）」「续聊：开着…现在在续聊 N 个群」「群里热闹加成：…」「群档案知识库：开着 · N 个群 / 成员对照 M 条 / 黑话 K 条 · 每晚 3:40 整理」。
- **睡眠模式卡片**：4 个磁贴——现在（醒着/安静期/睡着）、安静·睡·醒时间（如「安静 1 点 / 睡 2 点 / 醒 6 点 +45 分」）、排队等回复（主人 N 条 · 别人私聊 N 条）、群聊攒着（N 个群 / M 条，早上只回被叫到或聊到兴趣的）、预计醒来；下面一行统计「夜里拦下的消息：安静期 N 条 · 睡着 N 条 · 醒过 N 次 · 早上补回群聊 N 个」。
- **每个对话的余量**：按用量倒序，带彩色进度条、条数、token 用量、**这个会话花了多少钱**、最近时间、压缩记忆预览。
- **费用（按会话算）**：3 个磁贴（累计 / 今日 / 本月，各带请求次数和 token 量）+ 逐会话明细（私聊/群聊标签、花费、请求次数、输入/缓存/输出 token、最近时间）；和 `/费用` 是同一份数据。
- **已压缩的记忆**：每个压过的会话显示「N 条 → M 字」+ 摘要预览 + 压缩时间。
- **规则说明**：私聊要确认、群聊自动、统计口径。

## 7. 备份与恢复

- **备份内容（全量，不是只存人格描述）**：
  - 人格：所有 `personas`（system_prompt / begin_dialogs / tools / skills）+ 人格文件夹；
  - 配置档案与路由（abconf_mapping / umop_config_routing）；
  - 兴趣库：`interests.json` 全量（正式兴趣 + 还在观察的候选 + stats）；
  - 运行时状态：群聊发言记录 `speaker_log.json`、群档案知识库 `knowledge.json`、压缩记忆 `context_state.json`、搜索计数 `search_state.json`、睡眠状态 `sleep_state.json`；
  - 聊天记录：所有会话（cid / umo / 平台 / 标题 / persona / 时间 / token / 完整历史消息），最多 500 个会话；
  - 表情包库清单：`registry.json`、`selection_rules.json`、每个包的 `manifest.json` / `memes_data.json` / 文件数 / 体积 / 文件名（**不嵌图片二进制**，包本体在 `plugin_data/meme_manager/packs/`，换机时用它的导入接口搬）；
  - 本插件全部配置（14 段）。
- **位置**：`data/plugin_data/astrbot_plugin_dafeiyu_core/backups/dafeiyu-backup-YYYYmmdd-HHMMSS.json`。
- **时机**：每晚 `backup.hour:minute`（默认 3:00，趁她睡着做）自动一次，只保留最新 `keep`（默认 3）份；也可以 `/备份 现在`。
- **恢复顺序**：人格文件夹 → 人格 → 配置档案与路由 → 兴趣库 → 运行时状态 → 插件配置（最后热重载，顺序不能反，否则会读到旧配置）。
- **恢复范围**：人格、文件夹、配置档案与路由、兴趣库、发言记录 / 群档案知识库 / 压缩记忆 / 搜索计数 / 睡眠状态、插件配置。**聊天记录和表情包清单只作存档导出**，不会被自动写回（避免覆盖线上会话/别人的表情包库）；要找回某段聊天记录直接看备份 JSON 里的 `conversations`。
- **恢复会覆盖现有数据**，动手前先「立即备份」或 `/备份 现在`。
- 换机/重装：拿 `dafeiyu-backup-*.json` 在页面「备份 → 导入」或 `/备份 恢复` 即可（前提是同版本插件已装好）。

## 9. 常见问题排查

**Q1：群里叫她不理？**
检查：① 消息里有没有关键词「鲸/大肥鱼/肥鱼/鱼鱼」；② `group_wake.enabled` 和 `bot_filter` 是否包含当前平台；③ 随机搭话默认只有 5%、15 分钟一次，本来就不常回；④ 兴趣接话要相关度够且掷中概率。

**Q2：她回「发不了图」或干脆没图？**
检查 `meme.enabled`、meme_manager 里是否装了包且默认规则指向 `qq-emoji-collection`；普通回复配图还受 `humanizer.image_reply_probability`（45%）和 `image_min_gap_seconds`（120 秒）限制，纯聊两句没图是正常的。

**Q3：问她不知道的事她没去搜？**
检查 `search.enabled`、是否触发了 `daily_limit`（80 次/天）或 `cooldown_seconds`（6 秒）；再确认人格「大肥鱼」的工具白名单里有 `web_search`、`web_fetch`。

**Q4：命令发了没反应？**
`/上下文`、`/压缩`、`/报告`、`/费用`、`/备份` 只有主人能用，别人发没有任何反应；先在私聊发 `/主人` 确认身份。`/兴趣` 的写操作也只给主人。

**Q5：改了配置没生效？**
页面上要点对应段的「保存」；保存后会热重载。群聊巡检类参数（`group_check_interval_seconds` 等）下一轮巡检才生效。

**Q6：改了插件文件不生效？**
标准三步：`chmod 644` 改过的文件 → `chmod -R a+rX` 插件目录 → 删掉 `__pycache__` → 在插件页「重载」。重载日志应有「已把 29 个子模块处理器绑定到主模块」「已把 9 个 LLM 工具绑定到主模块」「v2.2.0 已加载…」和「睡眠模式=True（安静 1 点 / 睡 2 点 / 醒 6 点+45 分）」。

**Q7：群聊压缩太频繁 / 太懒？**
调 `group_min_messages`（几条才压）、`group_pause_seconds`（安静多久）、`group_idle_minutes`（多久没聊就压）、`group_auto_ratio`（余量阈值）；彻底关掉用 `group_auto_compress=false`。

**Q8：压缩完感觉她忘了之前的事？**
压缩是把旧对话总结成【压缩记忆】注入，不是删记忆；连续多次压缩会把旧摘要并进新摘要。要找回原样人格设定用 `/备份 恢复`。

**Q9：私聊收不到提醒 / 每晚报告？**
检查 `notify.private_umos` 是否包含你那个私聊会话（形如 `aiocqhttp:FriendMessage:123456789`），以及 `notify.nightly_report`、`backup.enabled` 是否开着。

**Q10：搜索老失败？**
DeepSeek key 失效/欠费会失败，此时若 `fallback_baidu=true` 会走百度；两边都失败就是网络或配置问题（插件页「配置 → 联网搜索」可填独立 `api_key`）。

**Q11：兴趣莫名其妙没了 / 一直在？**
临时话题 3 天不聊自动忘、正式兴趣 7 天不聊自动清；人设种子（鲸鱼/白饭/摸鱼/表情包）和主人相关的（含主人聊到的）带 `pinned`，永不清理。想永久保留就在页面「收进兴趣」或 `/兴趣 加`。

**Q12：费用看着不对 / 是估算的吗？**
是真实 token 计数（AstrBot 每次调用模型都会落一条用量记录），按 `cost` 段牌价换算；换模型/官方调价就在这里改价格。`conversations.token_usage` 只存最近一次用量，所以别拿它跟账单对比——账单读的是完整历史。
勾了「峰谷计价」后，会按 DeepSeek 官方峰谷价（deepseek-flash：峰 2/0.04/8、空闲 1/0.02/4 元每百万 token）逐条按时间判峰谷再算，历史账单也会重算；默认不勾，还是用单一牌价（2/0.2/3）。峰时默认北京时间工作日 9:00-12:00、14:00-18:00，周末和 `peak_holidays` 里的日期全天算空闲。

**Q13：群里她怎么知道是谁在说话？**
她给群聊记了「谁说了什么」的发言记录（`speaker` 段，默认留最近 8 条 / 2 小时），每轮回答前按记录区分发言人。她只记得记录窗口内的内容，超出窗口或刚重启（记录落盘会恢复）之前的不一定记得。

**Q14：她怎么回了一句就不理了 / 或者老是插话？**
续聊是「回完 180 秒内、话题还相关」才接着接，最多 6 句；群里安静 120 秒或连续 2 次不相关就退出。想更黏/更冷淡调 `engaged_probability`、`engaged_max_turns`、`engaged_min_score`；热闹加成太吵就关 `lively_boost_enabled`。

**Q15：`/help` 现在回几条？**
一条，就是鲸鲸的命令表。插件用最高优先级的 custom filter 抢在 AstrBot 内置 help 前面处理了；如果哪天又冒出内置清单，把 `/help` 改成 `/菜单` 也行。

**Q16：页面打不开 / 白屏？**
页面要在 AstrBot 面板里打开（带登录态与页面 token），别把 iframe 地址单独拷到新标签；弹窗是插件自绘的（浏览器 sandbox 下原生 `prompt/confirm` 会被忽略，属正常）。

**Q17：夜里她怎么不理人？**
正常，睡眠模式：1 点后群里和别人的私聊只记不回，2 点后连你的消息也排队，早上 6 点后（+0~45 分随机）才处理。想立刻叫醒私聊发「起床 / 醒醒 / 别睡了」或 `/睡眠 醒`；想关掉整块关 `sleep.enabled`。

**Q18：备份里为什么没有表情包图片？**
备份是「全量资料」但**不嵌图片二进制**：表情包只存清单（registry / 规则 / 每包 manifest 与文件名、体积），图片本体在 `plugin_data/meme_manager/packs/`。换机时先用 meme_manager 的导入接口装包，再恢复备份即可对得上。

**Q19：群里那些外号/黑话她怎么知道？**
她每晚 3:40 会把每个群的聊天总结成一份「群档案」（昵称→外号、黑话、近期话题）存 knowledge.json，聊天时自动带上；所以「奈白的雪子 = tom」「ks = 开送」这类她能听懂。想要马上生效就发 `/群档案 更新`；不想要就关 `knowledge.enabled`。
